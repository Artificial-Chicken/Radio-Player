# Radio Player

A terminal-based internet radio player built with Python and the Textual framework. It features a CSS-styled interface for streaming radio directly from your command line.

## Features

- **Terminal Interface:** distinct TUI experience.
- **Custom Styling:** Themed using standard CSS.
- **Lightweight:** Runs efficiently in the terminal.
