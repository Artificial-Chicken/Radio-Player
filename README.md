📻 Radio Player

A lightweight, terminal-based internet radio player built with Python and the Textual framework. Enjoy your favorite streams with a retro-futuristic TUI (Text User Interface) styled completely with CSS.

✨ Features

Terminal Native: Runs entirely in your command line, perfect for headless servers or minimalists.

CSS Styled: The interface is built using Textual, allowing for rich, web-like styling within the terminal (see App.css).

Station Management: Add and manage your favorite radio stations directly within the application.

Lightweight: Minimal resource usage compared to web-based players.

🚀 Getting Started

Prerequisites

Python 3.8 or higher

Git

mpv (System audio player)

Linux (Debian/Ubuntu): sudo apt install mpv

macOS: brew install mpv

Windows: Download from mpv.io (ensure it's in your system PATH).

Installation

Clone the repository

git clone [https://github.com/Artificial-Chicken/Radio-Player.git](https://github.com/Artificial-Chicken/Radio-Player.git)
cd Radio-Player


Install Dependencies

pip install textual


🎮 Usage

To start the radio player, simply run the python script:

python radio.py


Controls

Navigation: Use your mouse or keyboard (Arrow keys/Tab) to select stations.

Quit: Press q.

🎨 Customization

Want to change the look? Edit App.css!
The application uses CSS for all styling. You can change colors, borders, and layout without touching the Python code.
